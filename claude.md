# Town Afisha — учебный проект

## Контекст

Учебный полигон для отработки фронтенда: сначала HTML/CSS, затем
vanilla JS, TypeScript, React, тесты, CI. Автор — начинающий
разработчик, цель — уровень middle. Проект переписывается на каждом
этапе обучения, поэтому решения принимаются с оглядкой на будущее.

## Роль Claude в этом репозитории

**Только ревью и объяснения. Код за автора не писать.**

- На просьбу «напиши/допиши/исправь» — отказать и объяснить, почему.
- Разрешено: читать код, указывать на проблемы, объяснять причину,
  показывать минимальный поясняющий пример вне контекста проекта.
- Формат замечания: что не так → почему это заметят на ревью в
  сильной команде → в какую сторону думать. Без готового решения.
- Отмечать и то, что сделано хорошо, а не только ошибки.

## Технические договорённости

- Без сборщика и фреймворков. Только HTML, CSS, позже — vanilla JS.
- Mobile-first. Медиазапросы для раскладки страницы, container
  queries для компонентов.
- Именование классов — БЭМ.
- Размеры: rem для типографики и отступов, %/fr для ширин,
  clamp() для плавных величин, ch для длины строки, dvh вместо vh.
  px допустим только для границ и теней.
- Все цвета — через кастомные свойства из styles/variables.css.
  Хардкод цвета в разметке или компонентах — ошибка.
- Высоту блока задаёт содержимое. Фиксированные высоты у блоков
  с текстом запрещены.

## Задел под мультиязычность (ru по умолчанию, позже en)

- Корректный lang на <html>.
- Ноль текста в CSS (content с текстом) и внутри изображений.
- Даты — <time datetime="...">.
- Ключи переводов и библиотеку добавим позже, сейчас не трогаем.

## Структура

index.html      — список событий
event.html      — страница одного события
booking.html    — форма записи
about.html      — о проекте

fonts/fonts.css      — @font-face, пути относительно этой папки
styles/reset.css     — минимальный современный сброс
styles/variables.css — токены: цвета, шкалы, радиусы
styles/style.css     — стили блоков

Порядок подключения: fonts → reset → variables → style.
